## C18 research (16 Nov) — bade factory / ERP kaise handle karte hain
- **Planned scrap (SAP, Dynamics 365):** 3 jagah: *Assembly scrap* (parent qty badhao: 200 PCS order + 10% => 220 ka production order, 200 good), *Component scrap* (kisi ek input ka consumption badhao), *Operation scrap* (routing step ka loss, agle step ki qty ghatati hai). Planned (requirements/cost) aur Actual scrap (operator report karta hai) alag rakhte hain. D365 me variable % + constant (fixed qty per order) dono.
- **Tolerance:** Underdelivery / Overdelivery tolerance (jaise 10%): order is range me aa jaye to complete maana jata hai; usse kam ho to naya balance order trigger; over limit par error.
- **Wire/cable industry:** pichhle actual scrap ke history se fixed % allowance (UL article: standard weight par ~2%), + mass-balance (kharida hua vs becha hua) se giveaway/loss allowance. Scrap ko recoverable value par daam do (copper recover hota hai). Thai study: copper scrap 10.9%, PVC 12.2% — plant-specific.
- **Takeaway:** koi bhi fixed % ko "sach" nahi maanta — % ek *planned estimate* hai jo history se update hota hai, actual alag record, aur customer-side tolerance (+/- %) + balance order se gap handle hota hai. Hamare C18 ke options (1) learned loss, (2) Short/Extra + balance/short close, (3) good vs ordered — teeno isi pattern se match karte hain. Naya idea: **tolerance %** (order/customer par) — "Short close" tab auto-allowed jab tolerance ke andar ho. Final decision real test data ke baad (C18 PARKED).
