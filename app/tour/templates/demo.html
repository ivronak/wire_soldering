🎓 1-ક્લિક ઓટો ડેમો

આ ડેમો પોતે જ સોફ્ટવેર ચલાવશે — ક્લિક કરશે, ફોર્મ ભરશે, પોસ્ટ કરશે — અને દરેક પગલું ગુજરાતી અવાજમાં સમજાવશે. તમારે કંઈ કરવાનું નથી, ફક્ત જોવાનું અને સાંભળવાનું.

  • ખરીદી → પરચેઝ ઓર્ડર, GRN, ઇનવર્ડ QC, બિલ
  • સ્ટોક → લેજર, લોટ, વેલ્યુએશન
  • પ્રોડક્શન ઓર્ડર → કતાર, રિલીઝ
  • માલ આપવો / પાછો, સ્ટાર્ટ અને રાઉટિંગ
  • આઉટપુટ, તૈયાર માલ, સ્ક્રેપ, વેરિયન્સ

સમય: લગભગ 18–22 મિનિટ. વચ્ચે થોભો, ઝડપ (1.25×, 1.5×) અને અવાજ બંધ કરી શકાય. ગુજરાતી લખાણ નીચે પણ દેખાશે.

⚠️ ડેમો સાચી એન્ટ્રીઓ બનાવશે — પરચેઝ ઓર્ડર, GRN, QC, બિલ, પ્રોડક્શન ઓર્ડર, માલ આપવો/પાછો, રાઉટિંગ, આઉટપુટ વગેરે. ટ્રેનિંગ / ડેમો કોપી પર જ ચલાવો.

તમે આખું ચક્ર જોયું: પરચેઝ ઓર્ડર → GRN → QC → બિલ → સ્ટોક → પ્રોડક્શન ઓર્ડર → માલ આપવો / પાછો → સ્ટાર્ટ → રાઉટિંગ → આઉટપુટ → તૈયાર માલ → સ્ક્રેપ → વેરિયન્સ.
